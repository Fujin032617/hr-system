5. Fix Missing Profile (run SQL)

If login works but profile is missing, run this SQL in Supabase SQL Editor:

-- Insert profile for existing user (replace UUID or email)
INSERT INTO profiles (id, full_name, department, role)
SELECT id, 'Your Name', 'General', 'Employee'
FROM auth.users
WHERE email = 'YOUR_EMAIL_HERE'
ON CONFLICT (id) DO NOTHING;
